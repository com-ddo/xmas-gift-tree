# 星愿圣诞树

一个单页的交互式圣诞礼物，使用 Three.js 绘制深色夜空、绿色与红金装饰的粒子圣诞树、星尘地面和飘雪；MediaPipe Hand Landmarker 在浏览器本地识别手势。

## 运行

需要现代浏览器和网络连接（页面从 CDN 加载 Three.js、MediaPipe 和字体）。在此目录运行：

```bash
python3 -m http.server 4173
```

然后打开 <http://127.0.0.1:4173/>。使用摄像头需要在浏览器中允许权限。页面预置的 15 张照片会随网站公开；之后通过页面添加的照片仅保存在当前浏览器本地。`localhost` 与 HTTPS 才能使用摄像头。

## 操作

- 点击“加入照片”选择最多 20 张图片；单张限制 15 MB。点“翻看照片”聚焦浏览，点“移除”删除当前照片。
- 点击顶部“从头播放”可依次观看粒子雾、英文祝福、爱心和圣诞树；播放中可暂停或继续。圣诞树从底部向上慢速重组。手动点击、触屏或手势操作可随时中断自动播放。
- 开启手势后：拇指与食指捏合推进阶段，树完成后切换下一张照片；握拳聚合成树，张掌散开成粒子雾。画布单击可备用推进同一流程，树阶段点击空白处翻照片，点击照片可聚焦浏览；底部按钮和拖动旋转也可操作。
- “寄语”可修改称呼与祝福语，内容保存在当前浏览器。
- “开启手势”才会请求摄像头；关闭时视频流会停止。图像与手势推理均在本机处理。
